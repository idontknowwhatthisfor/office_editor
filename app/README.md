# app — the Android application module

## Purpose

The Gradle module that produces the APK/AAB: a Kotlin + Jetpack Compose shell (package
`com.officeeditor`) that bundles the web viewers from [`../web/`](../web/README.md) as assets.

## Contents

| Path | What it does |
| --- | --- |
| `build.gradle.kts` | Module build: SDK levels, version, release signing, and the `buildWeb` task. |
| `proguard-rules.pro` | Keeps `@JavascriptInterface` methods (the bridge) through code shrinking. |
| `src/main/AndroidManifest.xml` | Three activities, the "Open with" and share-to intent filters for the four MIME types, and the `FileProvider`. Deliberately no `INTERNET` permission. |
| [`src/main/java/com/officeeditor/`](src/main/java/com/officeeditor/README.md) | The Kotlin sources. |
| `src/main/res/` | Resources; see [below](#resources-srcmainres). (No README inside `res/`: the Android resource tools expect only resource folders there.) |
| `src/main/assets/web/` | Git-ignored. The built web app, written by `npm run build` in `web/`. |
| `templates/make_blank_templates.py` | Writes `res/raw/blank_document.docx` and `blank_spreadsheet.xlsx` by hand (A4, Calibri 11, no author metadata). Standard library only. |

### Resources (`src/main/res`)

The UI is Compose code, so there are no layout files.

| Path | What it holds |
| --- | --- |
| `values/strings.xml` | English strings. |
| `values-in/strings.xml` | Indonesian strings. Same keys as English except `app_name`, which is not translated. |
| `values/colors.xml` | `ic_launcher_background` (#2F5BD7). |
| `values/themes.xml`, `values-night/themes.xml` | `Theme.OfficeEditor`: the window theme (Material, no action bar), light and dark. Colours come from Compose (`Theme.kt`). |
| `drawable/ic_launcher_foreground.xml` | Launcher icon foreground (vector). |
| `mipmap-anydpi-v26/ic_launcher.xml` | Adaptive icon: background colour + foreground, also used as the monochrome icon. |
| `raw/blank_document.docx`, `raw/blank_spreadsheet.xlsx` | Templates behind "New document" / "New spreadsheet". Generated by `templates/make_blank_templates.py`; don't edit by hand. |
| `xml/share_paths.xml` | `FileProvider` paths: `cache/shared/`, where a copy is put before sharing. |

## How it works

- `buildWeb` runs `npm run build` in `web/` and `preBuild` depends on it, so every Android build
  includes the current web app. It is skipped when `web/src`, `web/scripts` and the web config
  files are unchanged.
- Release builds have code and resource shrinking on. Signing reads `keystore.properties` in the
  project root; without it the release build is signed with the debug key and must not be
  published.

## Dependencies & relationships

- Versions are in [`../gradle/libs.versions.toml`](../gradle/libs.versions.toml): AGP 9.1.1,
  Kotlin 2.3.21, Compose BOM 2026.09.00, activity-compose 1.13.0, webkit 1.14.0.
- `compileSdk` 37, `targetSdk` 36, `minSdk` 26, Java 17 bytecode.
- JUnit is declared, but there are no test sources.

## Usage notes

See the [root README](../README.md#build-and-run) for build commands. To regenerate the blank
templates:

```bash
python3 app/templates/make_blank_templates.py
```

To release, raise `versionCode`/`versionName` here and the version in `web/package.json`.
