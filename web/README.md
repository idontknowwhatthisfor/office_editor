# web — the viewers and editors (Vite + TypeScript)

## Purpose

The web app that renders and edits documents. It is built into `app/src/main/assets/web` and runs
inside the Android shell's WebView; it also runs in a desktop browser for development.

## Contents

| Path | What it does |
| --- | --- |
| [`src/`](src/README.md) | All TypeScript and CSS. |
| [`scripts/`](scripts/README.md) | Pre-build scripts (PDF.js assets, licence list) and the font CSS generator. |
| `index.html` | The single page; loads `src/main.ts`. |
| `package.json` | Dependencies (exact versions) and scripts. |
| `package-lock.json` | Lockfile; used by `npm ci`. |
| `vite.config.ts` | Build output to `../app/src/main/assets/web`, relative base URL, and the dev-only `/__dev-save` endpoint. |
| `tsconfig.json` | Strict TypeScript, ES2022, no emit (Vite bundles). |
| `public/` | Git-ignored, generated by `scripts/`: `pdfjs/` and `licences.json`. |

## Dependencies & relationships

- Runtime: `pdfjs-dist`, `pdf-lib`, `docx-preview`, `jszip`, `ssf`, `@fontsource/{tinos,arimo,carlito}`.
  Licences are in the [root README](../README.md#licences).
- Dev: `vite`, `typescript`, `@types/node`.
- Gradle's `buildWeb` task (in [`../app/build.gradle.kts`](../app/build.gradle.kts)) runs
  `npm run build` here before every Android build.

## Usage notes

```bash
npm ci
```

```bash
npm run dev
```

```bash
npm run build
```

```bash
npm run typecheck
```

- `npm run build` type-checks (`tsc --noEmit`) and then bundles.
- Dev server: with no bridge, the page shows a file picker. `?file=/@fs/<repo>/test-files/sample.docx`
  opens a file directly (`&edit`: edit mode, `&print`: print layout).
- `.claude/launch.json` starts the same server on port 5183 as `web-viewers`.
- In dev, a page can `POST` a file it built to `/__dev-save?name=x.docx`; it lands in
  `test-files/out/` for checking in Word, Excel or PowerPoint.
- The print layout can be printed as the phone does with headless Chrome:
  `--headless=new --print-to-pdf=out.pdf <url>`.
- There are no automated tests; checking is done against Office and on the phone (see
  the [root README](../README.md#testing)).
